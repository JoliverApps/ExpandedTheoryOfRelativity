# Expanded Theory of Relativity

**On a Geometric Origin of Quantum Mechanics from Expanded Relativity**  
J. Manuel Oliveira

**[Read the current manuscript](https://joliverapps.github.io/ExpandedTheoryOfRelativity/)**

This website is the author's authoritative living edition of the manuscript. Dated downloadable editions are maintained separately in preprint repositories and can point readers to this address for the current text.

The manuscript is maintained directly in `index.html`. Its equations, figure, bibliography, accessibility features, reading preferences, and public visits counter are included in the website.

See [BUILD.md](BUILD.md) for editing and publishing instructions.
