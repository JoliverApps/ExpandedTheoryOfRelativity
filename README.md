# Expanded Theory of Relativity

**On a Geometric Origin of Quantum Mechanics from Expanded Relativity**  
J. Manuel Oliveira

[Read the latest version online](https://joliverapps.github.io/ExpandedTheoryOfRelativity/) · [Download the latest PDF](https://joliverapps.github.io/ExpandedTheoryOfRelativity/ExpandedTheoryOfRelativity.pdf) · [View the LaTeX source](ExpandedTheoryOfRelativity.tex)

This repository is the author's primary location for the latest version of the manuscript. The PDF and HTML editions are generated from the same LaTeX source.

The [commit history](https://github.com/JoliverApps/ExpandedTheoryOfRelativity/commits/main/) records revisions. When referring to a particular revision, include its commit identifier or link to that commit.

## Source

`ExpandedTheoryOfRelativity.tex` is the main document. Chapter and appendix files, `Bibliography.bib`, and the TikZ figure are included alongside it.
